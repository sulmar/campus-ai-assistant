# UC-03 — Wyszukiwanie czynnego automatu z kawą

## Aktor

Student

## Cel

Znalezienie automatu z kawą, który jest aktualnie czynny.

## Powiązane wymagania

FR-01, FR-02, FR-03, FR-05

## Warunek wstępny

System posiada informacje o lokalizacji i dostępności automatów.

## Scenariusz podstawowy

1. Student pyta: „Gdzie znajdę czynny automat z kawą?”.
2. System wyszukuje automaty z kawą.
3. System sprawdza ich dostępność.
4. System wybiera czynne automaty.
5. System prezentuje znalezione automaty i ich lokalizacje.

## Scenariusze alternatywne

- **3a. Nieznany status automatu:** System nie przedstawia go jako czynnego, ale może poinformować o nieznanej dostępności.
- **4a. Brak czynnych automatów:** System informuje studenta, że nie znaleziono czynnych automatów.

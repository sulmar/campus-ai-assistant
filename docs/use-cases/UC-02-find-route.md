# UC-02 — Wyznaczanie trasy do miejsca

## Aktor

Student

## Cel

Uzyskanie wskazówek, jak dotrzeć do wybranego miejsca.

## Powiązane wymagania

FR-01, FR-03, FR-04

## Warunek wstępny

Znana jest lokalizacja docelowa.

## Scenariusz podstawowy

1. Student prosi o wyznaczenie trasy, np. „Jak dojść do sali A101?”.
2. System ustala lokalizację docelową.
3. System ustala punkt początkowy.
4. System wyznacza trasę.
5. System prezentuje trasę studentowi.

## Scenariusze alternatywne

- **3a. Nieznany punkt początkowy:** System prosi studenta o wskazanie miejsca, z którego wyrusza.
- **4a. Nie można wyznaczyć trasy:** System informuje studenta o problemie.

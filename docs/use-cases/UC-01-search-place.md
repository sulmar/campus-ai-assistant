# UC-01 — Wyszukiwanie miejsca lub obiektu

## Aktor

Student

## Cel

Znalezienie sali, budynku lub automatu z kawą na kampusie.

## Powiązane wymagania

FR-01, FR-02, FR-03

## Warunek wstępny

System posiada informacje o miejscach i obiektach na kampusie.

## Scenariusz podstawowy

1. Student zadaje pytanie w języku naturalnym, np. „Gdzie jest sala A101?”.
2. System rozpoznaje, jakiego miejsca szuka student.
3. System wyszukuje wskazane miejsce.
4. System prezentuje jego lokalizację.

## Scenariusze alternatywne

- **3a. Nie znaleziono miejsca:** System informuje studenta o braku wyników.
- **3b. Znaleziono kilka pasujących miejsc:** System przedstawia możliwe wyniki i prosi studenta o doprecyzowanie wyboru.

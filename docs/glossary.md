# Słownik domenowy

Słownik domenowy (Domain Glossary) definiuje pojęcia używane w projekcie, aby wszyscy członkowie zespołu rozumieli je w ten sam sposób.

Pojęcia opisujemy językiem dziedziny, dla której tworzymy system, a nie językiem technologii.


## Pojęcia

| Pojęcie | Definicja |
|---|---|
| Student | Osoba studiująca na uczelni. |
| Sala | Pomieszczenie znajdujące się w budynku uczelni. |
| Budynek | Obiekt na kampusie, w którym mogą znajdować się sale. |
| Automat z kawą | Urządzenie umożliwiające samodzielny zakup kawy. |
| Lokalizacja | Położenie miejsca lub obiektu na kampusie. |
| Trasa | Droga łącząca dwie lokalizacje. |
